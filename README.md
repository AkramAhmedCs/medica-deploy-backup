# 💊 Medica

A simple medical website that allows you to book appointments and view your medical history.

---

## 📌 Installation

Clone the repository:

```bash
git clone https://github.com/SerajEldeen/PayFlow.git

cd Medica

```

---

## Setup

```bash
# working on the root [run both frontend and backend]
npm i
npm run dev

#working on the frontend [run only the frontend]
cd frontend
npm i
npm run dev

#working on the backend [run only the backend]

cd backend
npm i
npm run dev
```

## Important notes

### ** Always pull before pushing to avoid conflicts:**

```bash
git pull
```

### 📝 Git Conventional Commit Guidelines

We follow **Conventional Commits** for consistency in our Git history.

#### Commit Format:

```bash
git commit -m "type: your message"
```

### 📝 Git Commit Types

| Type     | Description                                           |
| -------- | ----------------------------------------------------- |
| feat     | Add a new feature                                     |
| add      | Add a new function or file                            |
| fix      | Fix a bug                                             |
| refactor | Code changes that neither fix a bug nor add a feature |
| delete   | Remove code or files                                  |
